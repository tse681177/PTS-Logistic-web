# PTS Logistics - B2B Их Хэмжээний Үр Тариа & Тээвэр Логистикийн Платформ

Нэг хуудаст B2B бөөний худалдаа, үр тариа (буудай, хивэг, шрот), тээвэр логистикийн нэгдсэн хяналтын веб систем.

## Онцлог боломжууд
- **Нэг хуудаст бүтэц (SPA)**: Гүйдэг мөр (Marquee Ticker) болон `sticky` навигаци, бүх хэсэг рүү smooth scroll (`scroll-mt-24`).
- **Захиалга шалгах (#tracking)**: 5 шатлалт визуал хүргэлтийн явц (Баталгаажсан -> Ачигдаж буй -> Замдаа яваа -> Зангилаанд ирсэн -> Хүргэгдсэн).
- **Мэдээллийн хатуу нууцлал**: Жолоочийн нэр, утас, машины дугаар, чингэлэгийн дугаарыг нийтийн ил тод сүлжээнд ХЭЗЭЭ Ч гаргахгүй (зөвхөн Админ/Диспетчер талд).
- **Ил тод самбар (#public-orders)**: Нийтийн аюулгүй захиалгуудын жагсаалт, шууд шалгах холбоос.
- **Бүтээгдэхүүн & Лаборатори (#products)**: "Бэлэн бараа" болон "Урьдчилсан захиалга", SGS/МХЕГ-ын албан ёсны шинжилгээний гэрчилгээ үзэх модал & PDF татах.
- **Тээврийн 2 загвар (#logistics)**: Авто замын шууд тээвэр (Route A) vs Төмөр замын вагон/чингэлэг (Route B), ачааны тооцоолуур.
- **Холбоо барих & Данс (#contact)**: Утсаар захиалга авч, банкаар төлөх 4 шатлалт журам, Хаан/Голомт данс.
- **Админ портал (/admin)**: Пин код (`admin2026`)-оор хамгаалагдсан, утасны захиалга бүртгэх, жолоочийн утас/дугаар оруулах, тээврийн шатлал шинэчлэх, бүтээгдэхүүн, шууд ханш удирдах.
